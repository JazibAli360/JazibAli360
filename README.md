# Jazib Ali

Creative technologist from Karachi, Pakistan. I make live visuals, real-time systems and AI film, and I build my own tools for them.

Self-taught. VFX since I was twelve, working since 2018. Now AI Visual Artist at Imagine Art.

**Recent work**
- **PRISMFEST'26, Karachi:** visual and lighting direction and live visuals for the main stage. Five headliners, a nine-face LED wall, 65 full-song visuals, and my own real-time plugins running live.
- **Somewhere In Karachi 2025:** a TouchDesigner system that took a live phone camera, separated the crowd with depth, and put them on the LED wall in real time.
- **Project Saaz, Coke Studio Pakistan:** 3D generalist on the self-playing sitar.
- **Knowledge-guided orchestration:** research with Ashad Qureshi on keeping approved creative decisions intact when AI is part of production. [Read it](https://jazibali360.com/research/knowledge-guided-orchestration)
